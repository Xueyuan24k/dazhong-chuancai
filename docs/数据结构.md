# 数据结构

## data/recipes_all.json

数组，每项一道菜：

```json
{
  "id": "d000",
  "name": "回锅肉",
  "cat": "肉食类",
  "ing": [
    {"n": "猪肉", "a": "500克", "note": "带皮，肥瘦相连"},
    {"n": "蒜苗", "a": "100克", "note": ""}
  ],
  "steps": [
    "把带皮的肥瘦相连的猪肉洗干净。",
    "锅烧热下油，肉片下锅爆炒，见肉片卷成灯盏窝时下豆瓣、豆豉、甜面酱炒香。"
  ],
  "feat": "色红亮，味咸鲜微辣回甜。",
  "note": "煮肉时不可过火，否则不易切片。",
  "terms": [{"t": "灯盏窝", "d": "指肉片受热卷曲后中间凹下的形状。"}],
  "editions": [1, 3]
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | `d000`…`d277`，稳定主键，用于列表点击与详情跳转 |
| `name` | 菜名，以书前目录为准做规范化 |
| `cat` | 三分类之一：`肉食类` / `家禽水产类` / `蔬菜类` |
| `ing[].n` | 用料名（已清掉 OCR 尾部的量词残留） |
| `ing[].a` | 用量，**统一为克**（`500克` / `50克`；少数按个数写作 `2个`） |
| `ing[].note` | 用料旁的小字说明，如「剁细」「切二粗丝」；同名料合并时写「各半」 |
| `steps[]` | 做法步骤，已去掉行首编号，渲染时按顺序生成圆形编号 |
| `feat` | 特点（书里的成品描述），可能为空 |
| `note` | 附注（心得、变通、注意事项），**原样保留不删** |
| `terms[]` | 命中的术语提示，每条 `{t: 词, d: 释义}`，上限 6 条（构建时追加） |
| `editions[]` | 该菜出现在哪几版，数字：`1` 修订版 / `2` 1979 初版 / `3` 图文版；`[1, 2, 3]` 表示三版都有 |


构建阶段由 `tools/build_app.py` 追加：

- `img`：`data:image/jpeg;base64,…`（有图才有此字段）

## data/glossary.json

书末《方言、名词、术语解释》整理：

```json
[
  {"t": "二粗丝", "k": ["二粗丝"], "d": "约二分见方的丝，比头粗丝细、比细丝粗。"}
]
```

`k` 为命中关键词（一个术语可能有多种写法），用于在菜谱正文里匹配；匹配到就把 `t` / `d` 挂进该菜的 `terms`。

## data/food_images.json

`{"菜名": "base64 字符串"}`，由 `tools/pack_images.py` 生成：长边压到 820px、JPEG 质量 70、渐进式。文件名与菜名不一致的三处别名写在脚本的 `ALIAS` 里（`麻辣豆腐→麻婆豆腐`、`豆瓣鱼→豆瓣鲜鱼`）。

## 模板占位符（web/app_template.html）

| 占位符 | 替换为 |
| --- | --- |
| `__COVER__` | `data:image/jpeg;base64,…`（开场封面） |
| `__DATA__` | 菜谱数组 JSON（紧凑格式） |
| `__TERMS__` | 术语数组 JSON |

替换后即为 `dist/index.html`，无任何外链。
