# 版本记录

> 括号内为 Android `versionCode`。

## V2.1 (21)

- 修复：致谢弹层未关闭时按返回键会直接退出到桌面。返回键现在先关任何弹层，再按 详情 → 列表 → 主界面 → 退出 逐级后退。

## V2.0 (20)

- 新增搜索：菜名、用料、分类、做法原文、术语一起比对，按接近程度排序，命中片段标红。
- 搜索结果分「我的菜谱」与「菜谱」两块；主界面标题下新增搜索入口，点一下即跳进搜索框。
- 首页底部改为两行：「共收录 278 道川菜。」/「源自一九七九年初版、修订版与图文版三本《大众川菜》。」，界面不再显示版本号。

## V1.14 (14)

- 278 张菜品图全部内嵌，成品 15.6 MB。
- 版本信息写入首页脚注。

## V1.13 及更早

- 278 道菜结构化完成：三份 PDF 共 1028 页 OCR，按坐标重建版式，按「用料—做法—特点—附注」切段。
- 用料统一折算克重（一斤 500 克、一两 50 克、一钱 5 克、一分 0.5 克）。
- 术语库 41 条挂进正文，204 道菜命中。
- 开场动画：印章封面自右向左翻页（双面纸页 + 书脊阴影 + 主投影 + 0.05 秒毛玻璃过渡）。
- 详情页横向三面板（配料 / 做法 / 补充），支持滑动与键盘翻页。
- 「我的菜谱」：拍照、备注、分类归组；自动覆盖备份 JSON；导出 A4 PDF。
- 图标按红章边界重新居中裁切。
